# Contributing

This repository currently contains a product and architecture specification. Keep changes scoped to the active milestone and do not add implementation before it is approved.

Every milestone is gated on its required GitHub Actions workflow being green on `main`. Use `corismix` in public attribution. Do not commit credentials, local paths, personal identity, or generated provider payloads. Playloom and its runtime/export templates use permissive licenses; see [Licensing](docs/LICENSING.md).
